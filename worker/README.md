# Заявки с формы в Telegram

Сайт статический (GitHub Pages), поэтому заявку в Telegram пересылает маленький
бесплатный сервер — Cloudflare Worker из файла `telegram-form.js`.
Токен бота хранится в секретах Worker, а не в коде сайта: иначе любой
посетитель увидел бы его и мог бы писать от имени бота.

```
форма на сайте → Cloudflare Worker (хранит токен) → Telegram-бот → вам в чат
```

## 1. Создайте бота

1. Откройте в Telegram [@BotFather](https://t.me/BotFather) и отправьте `/newbot`.
2. Придумайте имя и username бота (должен заканчиваться на `bot`).
3. BotFather пришлёт **токен** вида `1234567890:AA...`. Никому его не показывайте
   и не вставляйте в код сайта.

## 2. Узнайте свой chat_id

1. Найдите своего бота в Telegram и нажмите **Start** (или напишите ему что угодно).
2. Откройте в браузере, подставив свой токен:
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
3. Найдите в ответе `"chat":{"id":123456789` — это число и есть **chat_id**.
   Если ответ пустой (`"result":[]`), напишите боту ещё раз и обновите страницу.

## 3. Создайте Worker в Cloudflare

1. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com) — бесплатного
   тарифа хватит с запасом (100 000 запросов в день).
2. **Workers & Pages → Create → Create Worker**, назовите, например, `zerno-form`,
   нажмите **Deploy**.
3. **Edit code** → удалите пример, вставьте целиком содержимое `telegram-form.js`
   → **Deploy**.
4. **Settings → Variables and Secrets → Add**:

   | Имя               | Тип    | Значение                       |
   |-------------------|--------|--------------------------------|
   | `BOT_TOKEN`       | Secret | токен из шага 1                |
   | `CHAT_ID`         | Secret | chat_id из шага 2              |
   | `ALLOWED_ORIGINS` | Text   | `https://wyn1x234.github.io`   |

   Сохраните (**Deploy**).
5. Скопируйте адрес Worker вида `https://zerno-form.<ваш-аккаунт>.workers.dev`.

## 4. Подключите форму

В `index.html` найдите `data-endpoint=""` у формы и вставьте адрес Worker:

```html
<form class="event-form reveal" id="event-form" data-endpoint="https://zerno-form.<ваш-аккаунт>.workers.dev" novalidate>
```

Закоммитьте и запушьте — через минуту-две форма заработает на сайте.

## 5. Проверьте

Отправьте тестовую заявку с сайта — в Telegram придёт сообщение от бота.
Если не пришло: в Cloudflare откройте Worker → **Logs** (Real-time logs)
и отправьте заявку ещё раз — там будет видна ошибка от Telegram.

Частые причины:
- `chat not found` — вы не нажали Start у бота или ошиблись в `CHAT_ID`;
- `Unauthorized` — неверный `BOT_TOKEN`;
- в консоли браузера ошибка CORS или ответ 403 — адрес сайта не совпадает
  с `ALLOWED_ORIGINS` (без `/zerno` и без `/` на конце).

## Защита от спама

- Worker принимает заявки только с адресов из `ALLOWED_ORIGINS`.
- В форме есть скрытое поле-ловушка: боты его заполняют, и такие заявки молча отбрасываются.
- Имя, телефон и согласие проверяются ещё раз на стороне Worker.

Если спам всё же пойдёт, следующий шаг — капча Cloudflare Turnstile или лимит
запросов (Rate Limiting) в настройках Worker.

## Персональные данные

Галочка согласия ведёт на `privacy.html` — это **шаблон**. Перед запуском заполните
в нём всё в `[квадратных скобках]`. Заявки содержат имя и телефон, то есть
персональные данные по 152-ФЗ, и проходят через зарубежные сервисы
(Cloudflare, Telegram). Требования к согласию и к хранению данных в России
стоит уточнить у юриста.
